# Roadmap

## Milestone 1 — simulator

- ESPHome host build with SDL at 480 x 800
- fixed sample values
- main layout and direct charge button
- Today/Tomorrow interaction and YTD detail view

## Milestone 2 — read Homey data

- dynamic quarter-hour prices for today and tomorrow
- electricity and gas: today, week, month, YTD and previous year
- Sessy status, power and state of charge
- local cache and clear connection status

## Milestone 3 — control Homey

- start the existing charging Flow with one tap
- show confirmation after Homey accepts the Flow
- verify charging status through the connected charging device

## Milestone 4 — ELECROW hardware

- confirm hardware revision V1.2/V1.3
- configure the RGB display and GT911 touch controller
- verify portrait rotation and touch coordinates
- configure the backlight
- test USB installation and wireless updates
